# Olympic-Sports-Analysis
🏅 Olympic Sports Analytics Project

📌 Overview

The Olympic Sports Analytics Project is a comprehensive data-driven study of the Olympic Games, designed to uncover historical trends in participation, event structures, and medal distribution across decades. Using Microsoft Excel and Power BI, this project transforms raw datasets into 36 actionable insights (18 per tool), supported by clean visualizations and interactive dashboards.

The project also integrates SQL for validation and structured querying, ensuring analytical accuracy before visualization.

🎯 Objectives

Discover meaningful patterns and trends in Olympic history.

Analyze medal distributions by country, gender, and sport.

Track event growth and participation over decades.

Explore demographics such as gender balance and athlete age.

Showcase technical proficiency in data preparation, transformation, and visualization.

📊 Tools & Technologies

Excel → Pivot Tables, Slicers, Charts (Static EDA)

Power BI → DAX, Relationships, Drill-through, Dashboards (Dynamic Reporting)

SQL → Data validation, Aggregation, Joins

PowerPoint & Word → Final presentation deck & detailed documentation

🔍 Process

Data Sourcing → Historical Olympic dataset from GitHub (structured).

Data Cleaning & Transformation → Handling missing values, correcting data types, adding calculated fields.

Validation with SQL → Aggregations and checks for accuracy.

Excel Analysis → 18 static insights via Pivot Tables & Charts.

Power BI Analysis → 18 interactive insights with dashboards.

Reporting → Professional PowerPoint (data storytelling) + Word documentation.

📈 Key Insights

✔️ Gender participation trends across decades.
✔️ Medal dominance by countries, regions, and sports.
✔️ Evolution of Olympic events (Summer & Winter).
✔️ Athlete demographics (age, height, weight).
✔️ Impact of geography and culture on performance.

📂 Data Model (Simplified ERD)

Sport Table → List of sports & categories.

Event Table → Event details (Men/Women/Mixed).

City Table → Hosting & participating cities.

Games Table → Olympic editions (Summer/Winter).

NOC Region Table → Countries & regions.

Person Table → Athlete demographics.

Games Competitor Table → Linking athletes to editions.

Competitor Event Table → Participation & medals.

Medal Table → Gold, Silver, Bronze, N/A.

📌 Significance

Provides a historical perspective on Olympic evolution.

Enables evidence-based decision making for sports bodies.

Demonstrates integration of Excel, Power BI & SQL in real-world analytics.

Offers accessible insights via dashboards & storytelling for both technical and non-technical audiences.
